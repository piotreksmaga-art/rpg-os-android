# RPG OS Developer Panel v1

Panel dostępny jako zakładka **Dev**.

Funkcje:
- wersja aplikacji,
- pełny Self-Test,
- test ContextBundle,
- test backendu,
- ręczny backup diagnostyczny,
- odczyt i czyszczenie Anti-Crash log,
- przeładowanie stanu gry.

Self-Test nie wykonuje fabularnych akcji gracza i nie stosuje StatePatch.
