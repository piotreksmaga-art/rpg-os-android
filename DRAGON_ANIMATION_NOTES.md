# RPG OS — Dragon Logo Animation

Dodano:
- animowanego smoka wokół napisu SYSTEM RPG OS,
- lekką orbitę 2D w Jetpack Compose,
- niebiesko-turkusową smugę,
- tryby efektów: Minimalna / Standardowa / Pełna,
- dodatkowe cząsteczki tylko w trybie Pełnym,
- opcję wyłączenia animacji startowej,
- podgląd animacji w Ustawieniach.

Tryb Minimalny ogranicza ruch i efekty.
Tryb Standardowy jest domyślny.
Tryb Pełny dodaje cząsteczki i mocniejszą smugę.

Nie dodano ciężkich assetów 3D ani dużych plików graficznych.
