# Dragon Guardian 127

Wersja docelowa animacji smoka dla nagłówka RPG OS.

- szczegółowa głowa: rogi, grzywa, pysk, żuchwa, zęby, oko, wąsy, łapa;
- miękka poświata bez dużej turkusowej kuli;
- energetyczne ciało/ogon prowadzone po elipsie wokół logo;
- sześcienne wygaszanie przezroczystości: najjaśniej przy głowie, coraz słabiej ku ogonowi;
- tekst jest renderowany nad animacją;
- większa bezpieczna orbita wokół SYSTEM / RPG OS / sloganu;
- wolniejszy, majestatyczny ruch;
- Full = więcej segmentów i iskier, Standard = lżejszy rendering.
