UI tabs:
- Gra
- Status
- Czas
- Kronika
- Techniki

Package screen:

- select active campaign
- create a new campaign

Technique browser:
- reads canon_technique_index from active World Pack
- search by name
- shows category, rank, element, source status and wiki URL

Mission browser:
- reads missions_v3 from active campaign
- prioritizes active/assigned missions
