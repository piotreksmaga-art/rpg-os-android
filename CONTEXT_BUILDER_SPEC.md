# Context Builder v1

The app does not send the full database to the AI.

The current v0.2 bundle contains:
- player/scene snapshot,
- world time,
- active story threads,
- relevant NPCs,
- knowledge actually available to those NPCs,
- active/available missions,
- future world pressure,
- canon constraints,
- recent chapter manifests,
- selected long-term narrative memories.

Future versions can add semantic retrieval and token-budget scoring.
