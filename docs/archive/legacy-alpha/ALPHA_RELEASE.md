# RPG OS ALPHA

## Wersja
**1.2.0-alpha1** (`versionCode 120`)

Ta paczka jest od teraz jedyną bazą źródłową RPG OS.

## Zintegrowane moduły
- Anti-Crash
- DiagnosticLogger
- AutoRepair bazy
- bezpieczny ContextBuilder
- DevPanel
- Self-Test
- test ContextBundle
- test backendu
- backup diagnostyczny
- aktualizacja lokalna z APK
- aktualizacja online przez backend
- backup przed aktualizacją
- weryfikacja packageName / versionCode / podpisu / SHA-256
- panel MG
- kronika
- baza świata
- system kampanii

## Reguła wydań
Każdy przyszły build musi wywodzić się z tej paczki.
Nie należy mieszać jej z wcześniejszymi projektami v0.4 / 1.0 / 1.1.
