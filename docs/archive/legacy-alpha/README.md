# Legacy Alpha Archive

This directory preserves historical pre-roadmap / early-alpha documentation that is no longer canonical for the current RPG OS architecture.

Files are retained for forensic and recovery value only. They must not be treated as current architecture, current acceptance status, or current runtime contracts.

Canonical project references live under `docs/`, especially the master architecture, implementation roadmap, work protocol, coordination policy, and audit records.

Moving a file into this archive changes only its current repository location. Its original path and every earlier revision remain recoverable through Git history.
