# RPG OS ALPHA 1.2.0-alpha4 — UI Refresh

## Główna zmiana
RPG OS jest teraz prezentowany jako uniwersalny silnik kampanii.

Ekran startowy NIE zawiera żadnych odniesień do Naruto.

## Ekran startowy
- Nowa gra
- Kontynuuj
- Zapisy
- Galeria
- Ustawienia
- O programie

## Nowa gra
Dopiero po wybraniu "Nowa gra" pojawia się wybór świata.
Na razie dostępny jest wyłącznie:
- Naruto

Kod nawigacji jest przygotowany pod kolejne światy, ale nie są one jeszcze wyświetlane.

## Kampania
Główna dolna nawigacja została uproszczona do:
- Gra
- Postać
- Kronika
- Świat
- Menu

Pozostałe narzędzia znajdują się w Menu kampanii.

## Czat

- diagnostyka ContextBundle zachowana opcjonalnie.
