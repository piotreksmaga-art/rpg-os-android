# RPG OS ALPHA 1.3.0-alpha18-memory59

Aktualizacja pamięci kampanii i obsługi lokalnego AI.

- Pamięć robocza, epizodyczna i semantyczna oraz konsolidacja faz 55–59.
- Bekko ponownie sprawdza źródła i uprawnienia przed przekazaniem wyników.
- Cofnięcie ostatniej zatwierdzonej tury z potwierdzeniem, weryfikacją odtworzonego zapisu i unieważnieniem starej pamięci. Ręczne backupy pozostają nienaruszone.
- Krótszy kontekst lokalnego Directora dla Bielika 1.5B.
- Poprawka awarii aplikacji po otrzymaniu niepełnego JSON-u z modelu.

## Znane ograniczenia ALPHA

Jakość lokalnego Bielika pozostaje eksperymentalna. W teście Directora model wygenerował odpowiedź po angielsku i nieugruntowane pomysły mimo poprawnego formatu odpowiedzi. Nie jest to potwierdzenie poprawy jakości narracji ani zakończone porównanie Bielika bez/z Bekko.

To wydanie ALPHA zostało zamówione z ujawnionymi ograniczeniami. Nie oznacza globalnego zamknięcia bramki jakości faz 55–59 ani ukończenia późniejszych faz roadmapy. Bridge i provider Codexa pozostają dostępne wyłącznie w kompilacji laboratoryjnej.

Aktualizację instaluj przez panel „System i aktualizacje” lub pobierz załączony APK. Przed testowaniem cofania warto utworzyć ręczny backup kampanii.
